Company-related, internal config or something that should be used on this machine only and not in general lives only in `work/`.
During changes evaluate if it could be split into public and work-related. Public config should be prefered for most changes, unless they're company related.

When working with shortcuts config: prefer vim or helix-style keys when choosing shortcuts. Karabiner, WezTerm, Aerospace, Yazi, Claude keybindings and others -- all have their shortcuts so some may conflict, check relevant files when working with shortcut changes.
